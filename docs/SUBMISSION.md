# Hackathon submission (Tavily by Nebius - Stale-answer detector)
**TruthGuard AI** takes any LLM answer, extracts each factual claim, researches it with Tavily, and returns a per-claim status, freshness score, evidence confidence and source reliability, plus a cited corrected answer. Freshness is volatility-aware (prices age faster than history), conflicts between credible sources are surfaced instead of hidden, and corrections are only accepted when grounded in retrieved text. It ships as a React dashboard and a REST API (`POST /api/v1/verify`) that any LLM app can call after generating an answer. Why it matters: confident but stale answers (prices, versions, leadership, regulation) are a quiet failure mode for LLM products; per-claim evidence makes them auditable.
